# LLM_Serach.Engine-with-Langchain
This sleek Streamlit and CSS3 workspace pairs Gemini models with LangChain orchestration. It features conversational memory via native session state, real-time hyperparameter tuning, and a premium glassmorphism dark mode with glowing gradients. Python-dotenv secures API keys, while LangSmith V2 provides live execution tracing.
